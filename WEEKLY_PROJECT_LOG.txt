Topic: Project Selection, Domain Analysis & Requirement Engineering
Work Carried Out:
Investigated current challenges in e-commerce customer retention workflows, focusing on why traditional CRMs fail due to reliance on lagging indicators (e.g., exit surveys, post-churn support tickets). Formulated the concept of a real-time behavioral telemetry engine that computes leading indicators (inactivity velocity, cart abandonment frequency, order drop-off). Selected React + Vite for frontend UI, Express.js + Node.js for backend services, Socket.io for bidirectional WebSockets, and MongoDB Atlas for document persistence. Prepared System Architecture Block Diagram and baseline repository structure.

----------------------------------------------------------------------------------------
WEEK 2 (26.07.2026 - 01.08.2026)
----------------------------------------------------------------------------------------
Topic: Literature Review, Problem Formulation & Mathematical Model Specification
Work Carried Out:
Evaluated existing customer churn prediction literature, comparing static machine learning models against real-time rule-based scoring engines. Formulated the multi-variable weighted churn risk formula: Risk Score = w1 * f(Days Inactive) + w2 * g(Cart Abandon Rate) + w3 * h(Order Drop Rate), where w1 = 40% (Inactivity Gap up to 120 days), w2 = 30% (Cart Abandonment Rate), and w3 = 30% (Order Drop Rate). Defined risk classification boundaries: High Risk (>= 70), Medium Risk (40-69), and Low Risk (<= 39). Presented literature summary and mathematical formulation to project supervisor.
