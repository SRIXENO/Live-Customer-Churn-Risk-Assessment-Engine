# Live Customer Churn Risk Assessment Engine

Real-time customer risk scoring, behavioral telemetry monitoring, and automated recommendation overrides for e-commerce enterprise platforms.

## 🚀 Features
- **Real-Time Telemetry Pipeline:** Multi-variable mathematical risk scoring using activity signals.
- **Activity Simulator:** Continuous background event generation for live customer metrics.
- **Multi-Agent AI Negotiation Arena:** AI-driven retention dialogue simulator powered by Google Gemini.
- **Automated Autopilot & Overrides:** Trigger email retention campaigns or manually override AI recommendations.

## 🛠️ Quick Start
Run the launcher script:
```cmd
start.bat
```

Or start manually:
```bash
# Backend (Port 10000)
cd backend && pnpm dev

# Frontend (Port 5173)
cd frontend && pnpm dev
```
