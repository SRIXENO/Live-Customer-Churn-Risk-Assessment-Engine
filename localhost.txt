## 🧠 CHURN SCORING ENGINE — FULL LOGIC

Implement this EXACTLY in `backend/src/services/churnScorer.js`:

```
SCORE FORMULA (0–100):

Signal 1 — Days Since Last Purchase (Weight: 40%)
  0–15 days   → score = 0
  16–30 days  → score = 20
  31–45 days  → score = 50
  46–60 days  → score = 75
  61+ days    → score = 100
  weighted = signal1 * 0.40

Signal 2 — Cart Abandonment Rate (Weight: 35%)
  < 20%       → score = 0
  20–39%      → score = 25
  40–59%      → score = 55
  60–79%      → score = 80
  80–100%     → score = 100
  weighted = signal2 * 0.35

Signal 3 — Order Frequency Drop (Weight: 25%)
  Compare orders: last 30 days vs previous 30 days
  Increase or same → score = 0
  Drop 1–25%       → score = 20
  Drop 26–50%      → score = 50
  Drop 51–75%      → score = 80
  Drop 76–100%     → score = 100
  weighted = signal3 * 0.25

FINAL CHURN SCORE = weighted1 + weighted2 + weighted3

TIER CLASSIFICATION:
  0–35   → "Low"    → color: #10B981 (green)
  36–65  → "Medium" → color: #F59E0B (amber)
  66–100 → "High"   → color: #EF4444 (red)
```

The scoring job must:
1. Run every 30 minutes via node-cron
2. Fetch ALL customers from MongoDB
3. Calculate score for each customer
4. Save updated score to database
5. Emit `score_updated` event via Socket.io to ALL connected clients
6. Log execution time and customer count
